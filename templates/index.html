03 / HOW IT WORKS

Inside the Python workspace

The application logic is organized into reusable Python data structures and functions.

01 · DATA STRUCTUREapp.py

Dictionary

A dictionary stores information as key-value pairs. Chromosome IDs are keys and chromosome records are values.

GENOME_DATA = {
  "1": {
    "length": 1000000,
    "genes": [...]
  },
  "2": {...},
  "X": {...}
}
02 · VARIABLESapp.py

Variables

Variables hold values while the application processes a request, such as the selected chromosome or search term.

selected_chromosome = "1"
search_text = request.values.get(
    "gene_search", ""
)
chromosome_data = GENOME_DATA[
    selected_chromosome
]
03 · FUNCTIONSapp.py

Reusable functions

Functions divide the work into smaller tasks, making the code easier to read, test and maintain.

parse_fasta(text)
calculate_sequence_stats(sequences)
parse_annotation(text, file_type)
prepare_genes(genes, chromosome_length)
Data note

The built-in chromosome labels, gene names and coordinates are illustrative teaching records. They are not verified reference-genome annotations and must not be used for biological interpretation. Uploaded annotation coordinates are displayed only when they match the selected chromosome.
